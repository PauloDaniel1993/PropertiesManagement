# Alsappan Web

React + TypeScript frontend for Alsappan.

## Stack

- Vite
- React
- Zustand
- TanStack Query
- React Router
- React Hook Form
- Zod
- i18next/react-i18next
- lucide-react
- Vitest and Testing Library

## Commands

Run commands from the repository root using npm workspaces:

```powershell
npm run dev --workspace src/Alsappan.Web
npm run build --workspace src/Alsappan.Web
npm run test --workspace src/Alsappan.Web
npm run lint --workspace src/Alsappan.Web
```
