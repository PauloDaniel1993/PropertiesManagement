# Initial Seed Data Plan

This project starts with seed data that keeps the first implementation usable while preserving multi-tenant boundaries.

## Organizations

- `alsappan-demo`: default local development organization.

## Roles

- `Administrador`: full administrative access.
- `Gestor`: manages properties, contracts, residents, payments, documents, occurrences, and inspections.
- `Operador`: executes day-to-day operational actions with limited settings access.
- `Leitura`: read-only access to permitted modules.
- `Morador`: resident portal access to linked records and enabled self-service actions.

## Locales

- `pt-BR`: default locale and fallback.
- `en-US`: secondary supported locale.

## Domain Catalogs

- Property statuses: `Disponivel`, `Reservado`, `Alugado`, `Manutencao`, `Inativo`, `Arquivado`.
- Property types: apartment, house, commercial room, land, other.
- Contract statuses: draft, active, ending soon, ended, terminated, cancelled, archived.
- Payment statuses: pending, overdue, partially paid, paid, cancelled, disputed, archived.
- Utility account types: electricity, water, gas, internet, condominium fee, IPTU, insurance, other.
- Occurrence priorities: low, medium, high, urgent.
- Occurrence statuses: open, assigned, in progress, waiting, resolved, cancelled, archived.
- Inspection statuses: scheduled, in progress, completed, cancelled, archived.

## Demo Users

Concrete demo credentials must be generated by the seed runner in a later implementation task and documented only for local development.
